# Drawing Management

## Upload a drawing
1. Open the project → Drawings → Register drawing.
2. Enter drawing number, title, discipline and revision code.
3. Upload the drawing file.
4. Save. The revision starts as Draft.

## Approval workflow
Draft → Submit → Under review → Approved or Rejected.
Approved revisions lock the drawing number. New revisions get a new code (codes are never reused). Approving supersedes the previous approved revision; files are never overwritten.

## BOQ link
A new BOQ requires at least one currently approved revision from the same project.

## Spreadsheet import
Drawing Management does **not** support Excel/CSV register import or Download Import Template.
Register drawings by uploading a supported file (DWG, DXF, PDF as configured).

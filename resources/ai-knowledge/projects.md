# Projects

## Create a project
1. Open Projects → Create Project (requires `projects.create`).
2. Enter code, name, client, dates and location.
3. Save. Assign the project team so members receive project-scoped access.

## Progress and milestones
- Project milestones live under Planning / project schedule.
- Upcoming and overdue milestones are visible to users with project access.
- Site Diary and DPR capture daily site progress against the project.

## Reports
Open Reports (permission `reports.view`) and choose a project report. Financial report packs need financial report permissions.

# BOQ Management

## How to create a BOQ
1. Open the project → Drawing Management.
2. Upload a drawing file (DWG, DXF, PDF as supported) with a revision code.
3. Submit the revision for approval and get it **Approved**.
4. Only **currently approved** drawing revisions from the **same project** are eligible when creating a new BOQ.
5. Open the project → BOQ → Create BOQ.
6. Select one or more currently approved drawing revisions, enter the BOQ title, then add line items (or import items into a draft BOQ).
7. Save. Submit for approval when ready.

## Important rules
- Spreadsheet import of drawing *register metadata* is not available. Drawings are registered by uploading a file.
- Imported or manually entered BOQ lines stay draft until the BOQ is approved.
- Historical BOQs remain visible. Superseded drawing revisions stay linked for history.
- Editing is only allowed while the BOQ is draft or rejected.
- Totals use the ERP BOQ calculator (do not invent formulas).

## Why can't I create a BOQ?
Usually because the project has no currently approved drawing revision. Approve a drawing first, then create the BOQ.
